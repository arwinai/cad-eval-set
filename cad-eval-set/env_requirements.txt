# What tools/try_model.py and the model routes in common/ need. The CAD
# toolchain itself lives in the Docker base images (common/docker/), not
# here.
#
# Not pip-installable:
#   * FreeCAD 1.1 (only for --allow-host runs); set `FREECAD_CMD` to its
#       `freecadcmd` binary
#   * The SolidWorks COM API: a licensed SolidWorks install on Windows,
#       driven through pywin32
#   * Gemini CLI (`npm install -g @google/gemini-cli`, needs Node): the
#       gemini:* routes drive it; or set GEMINI_CLI (0.61.0 known good)
#   * Kimi Code CLI: the grok, kimi, deepseek and glm routes drive it,
#       expected at ~/.kimi-code/bin/kimi.exe; or set KIMI_CODE_CLI.
#       Windows: `irm https://code.kimi.com/kimi-code/install.ps1 | iex`,
#       macOS/Linux: `curl -fsSL https://code.kimi.com/kimi-code/install.sh | bash`
#       (2.1.1 known good)
